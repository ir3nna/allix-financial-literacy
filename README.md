# Allianz Academy — Финансова грамотност

Геймифицирана платформа за финансова грамотност за ученици 14–18 г. в България, създадена за Allianz Банк България.

**„Учи парите, играейки."** — мисии, XP, значки, класации и реални житейски сценарии.

## Стартиране

```bash
npm install
npm run dev
```

Отваря се на [http://localhost:3000](http://localhost:3000).

## Какво включва MVP-то

| Раздел | Описание |
|---|---|
| **Начало** | Дневна мисия, XP прогрес към следващо ниво, серия 🔥, „Продължи ученето", преглед на класацията |
| **Учи** | Карта с 8 свята (Моите пари → Финансова безопасност), 20 урока, заключени/отключени по ниво; съобразено с Националната стратегия за финансова грамотност и програмите на МОН |
| **Урок** | Поток: История → Концепция → Интеракция (слайдер/избор) → Куиз → Награда |
| **Мисии** | Дневно предизвикателство (нов въпрос всеки ден, +40 XP), 3 интерактивни практически мисии (семейни разходи, начини за спестяване, бюджет за екскурзия) + автоматични дневни/седмични |
| **Дуели** | Куиз битка 1v1 срещу съученик или Фин-бот (AI) с 3 нива на трудност; 5 въпроса по 15 сек., XP за победа |
| **Речник** | 34 термина с обяснение на ученически език и пример от живота; търсене и филтър по категория |
| **Финансов IQ** | Индекс 0–1000 от целия прогрес (уроци, куизове, дуели, мисии); титли от „Финансов новак" до „Финансов гений"; показва се след всеки урок, в профила и в дясната колонка |
| **Фини 🦉** | AI помощник „Финансовата сова": плаващ чат на всяка страница (обяснява понятия, дава съвети) + втори шанс с подсказка при грешка в куиз („Не се притеснявай. Нека опитаме по друг начин.") |
| **Класация** | Клас / Училище / Национална, с открояване на текущия потребител |
| **Профил** | Аватар, ниво, титла, статистики с Lucide иконки, мрежа от 9 значки, любими уроци (♥) |
| **Настройки** | Смяна на име и аватар, светла/тъмна/авто тема, 4 акцентни цвята |
| **Родителски портал** | `/parent` — напредък, силни/слаби страни и препоръки, генерирани от реалните резултати на детето |
| **Учителски портал** | `/teacher` — създаване на клас, задаване на домашни със срок, таблица с резултати, експорт на CSV отчет |
| **Админ портал** | `/admin` — добавяне на уроци, въпроси, игри, речник, видеа, значки и мисии (чернови в localStorage) |

## Съответствие с национални рамки

Съдържанието е изградено така, че да покрива утвърдените рамки за финансова грамотност в България:

| Рамка | Как я покриваме |
|---|---|
| **Национална стратегия за финансова грамотност (2021–2025)**, приета от МС, координирана от МФ с подкрепата на ОИСР | Уроците следват четирите компетентностни области от рамката на ОИСР: *Пари и транзакции* (Светове 1, 3), *Планиране и управление на финансите* (Светове 2, 7), *Риск и възнаграждение* (Светове 5, 6), *Финансов пейзаж* (Светове 4, 8 + данъци, права, евро) |
| **МОН — „Технологии и предприемачество“** (модул „Финансова грамотност“, V–VII клас) | Урокът „От идея до печалба“ (приход/разход/печалба, ценообразуване), бюджетиране, практическите мисии |
| **Актуалност 2026** | Всички суми са в **евро** (България е в еврозоната от 01.01.2026); отделен урок за прехода лев → евро с фиксирания курс 1.95583; гаранция на влоговете 100 000 € (стандарт на ЕС) |
| **Институционална точност** | НАП (данъци 10%), НОИ/НЗОК (осигуровки), БНБ (обмяна на левове), КЗП (потребителски права), ФГВБ (гарантирани влогове) |

> ⚠️ **Важно за маркетинга:** твърдението „одобрено/подкрепено от МОН“ изисква официална процедура (вписване в списъка на одобрените познавателни книжки и учебни помагала или партньорство по национална програма). Докато това не е факт, коректната формулировка е „*съдържанието следва Националната стратегия за финансова грамотност и учебните програми на МОН*“ — точно това пише и в приложението.

## Геймификация

- **XP**: 50 за урок + 25 за куиз + 50 бонус при перфектен резултат; повторение дава половин XP
- **Нива**: 1–50, по 100 XP на ниво, с титли („Нов спестовник" → „Allianz Майстор")
- **Серия**: брои поредни дни на активност
- **Значки**: отключват се при завършване на ключови уроци; „Дуелен майстор" — при 3 спечелени дуела
- **Дуели**: победа срещу бот носи 75/100/150 XP според трудността (Фин Новак/Умник/Майстор), срещу съученик — 100 XP; равенство 50, загуба 25. Препоръчаният бот следва нивото на потребителя; опонентите са симулирани (точност според ниво/трудност) до Supabase realtime интеграция

## Технологии

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS v4 със семантични токени (`surface/card/line/fg/muted/soft`) — тъмната тема и акцентните цветове се сменят само чрез CSS променливи (`.dark`, `data-accent`)
- Desktop оформление в стил Duolingo: странична навигация + дясна колонка с уиджети (ниво, серия, съвет на деня, мини класация)
- Градиентни карти с декоративна точкова шарка; всеки свят е с градиент в собствения си цвят
- 3D иконки от [Thiings](https://www.thiings.co) (50 бр., свалени локално в `public/thiings/`, 256px PNG) — светове, уроци, аватари, значки, медали, ботове, маскотът Фини; без емоджи иконки в интерфейса
- Къстъм CSS анимации (float, flame-pulse, pop-in) — с уважение към prefers-reduced-motion
- Allianz синьо `#0057FF` като акцент по подразбиране
- Framer Motion (анимации само с transform — устойчиви при throttled табове)
- shadcn-стил компоненти в `components/ui/`

## Структура

```
app/            — страници (dashboard, learn, lesson/[id], missions, leaderboard, profile)
components/ui/  — Card, Button, Progress, Badge
components/     — Nav (странична лента + мобилна долна лента)
lib/data.ts     — 8 свята, 20 урока с куизове (суми в евро), значки, мисии, mock класации
lib/game-state.tsx — XP/ниво/серия/прогрес, пази се в localStorage
```

## Фини — AI туторът

„Фини — Финансовата сова" (`lib/fini.ts`, `components/fini.tsx`) в демото отговаря от локална база знания (~20 теми: инфлация, ГПР, лихви, измами…). Интерфейсът `finiReply(въпрос, {име, ниво})` е проектиран така, че при LLM интеграция само тази функция се заменя с извикване към модела — чатът, куиз подсказките и правилата за безопасност (само образователни симулации, без съвети за реални пари) остават същите. При грешка в куиз Фини окуражава, задрасква грешния отговор и дава един втори опит; „перфектен куиз" бонусът остава само за безгрешно решаване от първия път.

## Следваща стъпка: Supabase

Състоянието в `lib/game-state.tsx` и данните в `lib/data.ts` са проектирани 1:1 по схемата от спецификацията (`users`, `lessons`, `progress`, `badges`, `user_badges`) — интеграцията изисква само подмяна на localStorage слоя с Supabase клиент.
